# MAMTA CARE CHARITABLE TRUST Website

React + Vite starter website for MAMTA CARE CHARITABLE TRUST.

## Run in VS Code
1. Install Node.js LTS.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Next step
Supabase can be connected after you review the website. The three forms are currently demo submissions and will later write to Supabase tables/storage.

## Assets
Replace `public/logo.png` and `public/upi-qr.png` with the Trust's actual logo and QR image when available.
